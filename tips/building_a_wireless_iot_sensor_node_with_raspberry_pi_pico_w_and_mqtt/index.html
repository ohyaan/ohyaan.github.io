    Building a Wireless IoT Sensor Node with Raspberry Pi Pico W and MQTT¶

    Create a wireless temperature and humidity sensor node using the $6 Raspberry Pi Pico W and report data over Wi-Fi to a central Raspberry Pi server using the lightweight MQTT protocol!

    Introduction¶

    In internet-of-things (IoT) projects, sending data efficiently from small sensors to a central database is a common challenge.

    By combining the Raspberry Pi Pico W (a low-cost micro-controller with Wi-Fi) and the MQTT (Message Queuing Telemetry Transport) publish-subscribe protocol, you can build low-power, wireless sensor nodes that report telemetry data to a central Raspberry Pi server.

    Architecture Overview¶

    1. The Sensor Node (Pico W): Reads data from a DHT22 sensor, connects to Wi-Fi, and publishes the payload (temperature/humidity) to an MQTT topic.
    2. The Broker (Raspberry Pi): Runs a Mosquitto MQTT broker that routes incoming sensor payloads to subscribers.

    Step 1: Set Up the MQTT Broker on the Raspberry Pi¶

    The central Raspberry Pi will host the MQTT broker (server) to receive all wireless messages.

    1. Install Mosquitto: 
      1
      sudo apt update && sudo apt install mosquitto mosquitto-clients -y
    2. Enable the Service: 
      1
      sudo systemctl enable mosquitto --now
    3. Configure Remote Connections: By default, newer versions of Mosquitto restrict connection to localhost only. We must allow external connections. 
      1
      sudo nano /etc/mosquitto/conf.d/external.conf
      Paste the following lines: 
      1
2
      listener 1883
allow_anonymous true
      Save the file and restart Mosquitto: 
      1
      sudo systemctl restart mosquitto

    Step 2: Wire the Sensor to the Pico W¶

    Connect a DHT22 (or DHT11)温湿度センサー to the Raspberry Pi Pico W.

    Wiring Diagram:¶

    • VCC (Sensor Pin 1) -> 3V3 OUT (Pico Pin 36)
    • Data (Sensor Pin 2) -> GP15 (Pico Pin 20)
    • GND (Sensor Pin 4) -> GND (Pico Pin 38) Note: If your DHT22 sensor does not have a built-in pull-up resistor, connect a 10k ohm resistor between the VCC and Data pins.

    Step 3: Flash MicroPython to the Pico W¶

    1. Download the latest MicroPython .uf2 bootloader for Pico W from micropython.org/download/rp2-pico-w.
    2. Hold down the BOOTSEL button on your Pico W, connect it to your computer via USB, and release the button.
    3. Drag and drop the downloaded .uf2 file onto the virtual drive named RPI-RP2. The Pico W will reboot running MicroPython.

    Step 4: Write the MicroPython Code¶

    First, upload the standard MicroPython MQTT library helper umqtt/simple.py to the Pico. In Thonny, go to Tools > Manage Packages, search for umqtt.simple, and install it.

    import time
import network
import machine
import dht
from umqtt.simple import MQTTClient

# Wi-Fi Credentials
WIFI_SSID = "Your_WiFi_Name"
WIFI_PASS = "Your_WiFi_Password"

# MQTT Configuration
MQTT_BROKER = "192.168.1.100" # Replace with your central Raspberry Pi IP
CLIENT_ID = "PicoWSensorNode"
TOPIC_TEMP = b"home/sensor/temperature"
TOPIC_HUM = b"home/sensor/humidity"

# Initialize DHT22 on GP15
sensor = dht.DHT22(machine.Pin(15))

def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    if not wlan.isconnected():
        print("Connecting to Wi-Fi...")
        wlan.connect(WIFI_SSID, WIFI_PASS)
        while not wlan.isconnected():
            time.sleep(1)
    print("Wi-Fi Connected! IP Info:", wlan.ifconfig())

def main():
    connect_wifi()

    # Establish MQTT connection
    print(f"Connecting to MQTT Broker: {MQTT_BROKER}...")
    client = MQTTClient(CLIENT_ID, MQTT_BROKER, keepalive=60)
    client.connect()
    print("Connected to MQTT broker!")

    while True:
        try:
            # Trigger sensor read
            sensor.measure()
            temp = sensor.temperature()
            hum = sensor.humidity()

            # Format and publish
            print(f"Temp: {temp}C, Hum: {hum}%")
            client.publish(TOPIC_TEMP, str(temp).encode())
            client.publish(TOPIC_HUM, str(hum).encode())

        except OSError as e:
            print("Failed to read sensor or publish message:", e)
            # Reconnect on error
            connect_wifi()
            client.connect()

        # Send data every 10 seconds
        time.sleep(10)

if __name__ == "__main__":
    main()
    Save main.py onto the Pico W. It will execute automatically when the Pico W receives power.

    Step 5: Subscribe and Verify the Data¶

    Go back to your central Raspberry Pi server terminal and run a command-line client to listen (subscribe) to the incoming MQTT messages.

    1. Listen to Temperature: 
      1
      mosquitto_sub -h localhost -t home/sensor/temperature
    2. Listen to Humidity: 
      1
      mosquitto_sub -h localhost -t home/sensor/humidity

    You should see telemetry values printing to the terminal console every 10 seconds!

    Troubleshooting¶

    • MicroPython OSError: [Errno 110] ETIMEDOUT:
      • Double check your Wi-Fi SSID and Password.
      • Verify that the Raspberry Pi IP (MQTT_BROKER) is correct and reachable from the Pico W (you can try pinging the Pi from another local PC).
    • Sensor read fails:
      • Double check your wiring. Make sure the data pin is connected to GP15 (Pin 20) and VCC has a stable 3.3V source.
