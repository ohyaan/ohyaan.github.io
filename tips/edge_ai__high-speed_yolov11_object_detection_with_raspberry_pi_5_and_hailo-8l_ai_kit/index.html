    Edge AI: High-Speed YOLOv11 Object Detection with Raspberry Pi 5 and Hailo-8L AI Kit¶

    Deploying artificial intelligence models on edge devices has historically been limited by computational power and thermal constraints. With the introduction of the Raspberry Pi 5 and the official Raspberry Pi AI Kit (powered by the Hailo-8L NPU offering 13 TOPS of performance), real-time, high-frame-rate deep learning inference is now a reality.

    This guide provides a comprehensive tutorial for setting up the Hailo-8L hardware, configuring PCIe Gen 3 speeds, compiling YOLOv11 models into Hailo's proprietary HEF (Hailo Executable Format) pipeline, writing a high-performance Python application for real-time video detection, and implementing automated security alerts via a Discord Webhook.

    1. Hardware Architecture & Setup¶

    The Raspberry Pi AI Kit features a Hailo-8L M.2 AI Acceleration Module (Key A+E) mounted on the Raspberry Pi M.2 HAT+.

    graph TD A[Raspberry Pi 5 CPU] ---|16-way FPC Cable| B[M.2 HAT+] B ---|PCIe Gen 2/3 x1 Interface| C[Hailo-8L M.2 Module] C ---|13 TOPS NPU| D[Hardware Accelerated Inference] E[Raspberry Pi Camera Module v3] -->|CSI Interface| A

    Required Hardware:¶

    • Raspberry Pi 5 (8GB or 4GB recommended)
    • Raspberry Pi 27W USB-C Power Supply (essential to supply enough power to the PCIe slot)
    • Raspberry Pi M.2 HAT+ (with flat flexible cable)
    • Hailo-8L M.2 AI Module (included in the AI Kit)
    • Raspberry Pi Camera Module v3 (or a high-quality USB webcam)
    • Active Cooler (highly recommended; the Hailo module generates significant heat under sustained load)

    Physical Installation:¶

    1. Ensure the Raspberry Pi 5 is powered off and disconnected from the power supply.
    2. Install the Active Cooler onto the Raspberry Pi 5.
    3. Attach the spacer standoffs to the Pi 5 motherboard.
    4. Insert the Hailo-8L M.2 module into the M.2 slot on the M.2 HAT+ at a slight angle, push it down, and secure it with the included screw.
    5. Connect the flat flexible cable (FPC) from the PCIe connector of the Pi 5 to the M.2 HAT+ connector, ensuring proper orientation.
    6. Mount the M.2 HAT+ on top of the Pi 5 spacer standoffs and secure the screws. Connect the GPIO pass-through pins if needed.

    2. Operating System & PCIe Gen 3 Optimization¶

    By default, the Raspberry Pi 5 configures the PCIe connection at PCIe Gen 2 speeds (5.0 GT/s) to ensure maximum compatibility and electrical stability. However, the Hailo-8L module can leverage PCIe Gen 3 (8.0 GT/s) to minimize latency when transferring high-resolution image frames from the system memory (RAM) to the NPU.

    Step 1: Update the Bootloader and OS¶

    Before modifying settings, ensure your system is running the latest kernel and firmware:

    Step 2: Force PCIe Gen 3 Speeds¶

    Open the firmware configuration file: 

    1

    Append the following parameters to the bottom of the file to force PCIe Gen 3 speed and enable the external PCIe port: 
    1

    Save the file (Ctrl+O, then Enter) and exit (Ctrl+X).

    Step 3: Reboot and Validate Connection¶

    Reboot the device to apply the new hardware settings: 

    1

    Once logged back in, check the PCIe link status using lspci: 
    1
    lspci -vvv
    Find the Hailo device in the output list. Verify that the LnkSta (Link Status) reports Speed 8GT/s and Width x1.

    4. Converting YOLOv11 to Hailo Executable Format (HEF)¶

    Unlike standard CPUs/GPUs which read raw PyTorch .pt or ONNX weight files directly, the Hailo-8L NPU executes static computational graphs optimized for its hardware clusters. This compiler output is stored in a .hef file.

    To convert a custom or pre-trained YOLOv11 model, use the Hailo Dataflow Compiler (DFC) (usually run on a powerful host PC due to the RAM requirements of the quantization process).

    graph LR A[YOLOv11 PyTorch .pt] -->|Export| B[ONNX Model] B -->|DFC Optimization| C[Quantization: Calibration Dataset] C -->|DFC Compiler| D[Hailo HEF Model .hef]

    Step 1: Export YOLOv11 to ONNX¶

    On your machine containing the PyTorch model, export the model with static dimensions:

    import os
import sys
import time
import cv2
import numpy as np
from PIL import Image
import requests
from hailort import Device, InferVDevice, ConfigureParams, InputFormatType, HailoStreamInterface

# Configuration
HEF_FILE = "yolov11n.hef"
DISCORD_WEBHOOK_URL = os.environ.get("DISCORD_WEBHOOK_URL")
CONFIDENCE_THRESHOLD = 0.50
ALERT_COOLDOWN_SECONDS = 30
TARGET_CLASS_ID = 0  # Person

# Simple coco labels list
LABELS = {0: "person", 1: "bicycle", 2: "car", 3: "motorcycle", 5: "bus", 7: "truck"}

class SmartSecurityCamera:
    def __init__(self, hef_path):
        self.target_vdevice = InferVDevice()
        self.network = self.target_vdevice.configure(hef_path)
        self.configured_network = self.network[0]

        # Configure input/output streams
        self.input_stream = self.configured_network.get_input_streams()[0]
        self.output_stream = self.configured_network.get_output_streams()[0]

        self.input_shape = self.input_stream.get_shape() # Usually (640, 640, 3)
        self.last_alert_time = 0

    def preprocess(self, frame):
        # Resize to model expectations
        resized = cv2.resize(frame, (self.input_shape[1], self.input_shape[0]))
        # Convert BGR to RGB
        rgb = cv2.cvtColor(resized, cv2.COLOR_BGR2RGB)
        return np.expand_dims(rgb, axis=0).astype(np.uint8)

    def postprocess(self, output_data, original_width, original_height):
        # Decode NPU output buffers
        # Note: Raw outputs depend on your model compilation structure.
        # This acts as a standard parser stub for bounding box coordinates
        detections = []
        raw_boxes, raw_scores, raw_classes = output_data

        for i, score in enumerate(raw_scores):
            if score > CONFIDENCE_THRESHOLD:
                box = raw_boxes[i]  # [ymin, xmin, ymax, xmax] normalized
                class_id = int(raw_classes[i])
                detections.append({
                    "box": [
                        int(box[1] * original_width),
                        int(box[0] * original_height),
                        int(box[3] * original_width),
                        int(box[2] * original_height)
                    ],
                    "class_id": class_id,
                    "score": float(score)
                })
        return detections

    def trigger_discord_alert(self, frame, label, score):
        current_time = time.time()
        if current_time - self.last_alert_time < ALERT_COOLDOWN_SECONDS:
            return  # Suppress alerts within cooldown window

        if not DISCORD_WEBHOOK_URL:
            print("Warning: DISCORD_WEBHOOK_URL is not configured. Skipping notification.")
            return

        print(f"[*] Intruder detected! Class: {label} ({score:.2f}). Sending alert...")
        self.last_alert_time = current_time

        # Save frame temporarily
        alert_img_path = "/tmp/alert_frame.jpg"
        cv2.imwrite(alert_img_path, frame)

        # Build payload
        payload = {
            "content": f"⚠️ **Security Alert**: `{label}` detected with {score*100:.1f}% confidence!"
        }

        with open(alert_img_path, "rb") as f:
            files = {"file": ("alert.jpg", f, "image/jpeg")}
            try:
                r = requests.post(DISCORD_WEBHOOK_URL, data=payload, files=files)
                if r.status_code == 200 or r.status_code == 204:
                    print("[+] Discord notification sent successfully.")
                else:
                    print(f"[-] Failed to send Discord API payload: {r.status_code} - {r.text}")
            except Exception as e:
                print(f"[-] Network error during Discord dispatch: {e}")

    def run(self):
        cap = cv2.VideoCapture(0)  # Bind to camera interface
        if not cap.isOpened():
            print("Error: Could not open video device.")
            return

        print("[*] Starting hardware accelerated video loop. Press 'q' to exit.")
        while True:
            ret, frame = cap.read()
            if not ret:
                break

            h, w, _ = frame.shape
            input_tensor = self.preprocess(frame)

            # Send tensor to Hailo NPU for computation
            with self.input_stream.write(input_tensor), self.output_stream.read() as output_tensor:
                # Process outputs
                detections = self.postprocess(output_tensor, w, h)

            for det in detections:
                box = det["box"]
                class_id = det["class_id"]
                score = det["score"]
                label = LABELS.get(class_id, f"ID_{class_id}")

                # Draw bounding box
                cv2.rectangle(frame, (box[0], box[1]), (box[2], box[3]), (0, 255, 0), 2)
                cv2.putText(frame, f"{label} {score:.2f}", (box[0], box[1] - 10),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)

                # Send alert if target is detected (e.g. Person)
                if class_id == TARGET_CLASS_ID:
                    self.trigger_discord_alert(frame, label, score)

            cv2.imshow("Hailo-8L YOLOv11 Inference", frame)
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break

        cap.release()
        cv2.destroyAllWindows()

if __name__ == "__main__":
    if not os.path.exists(HEF_FILE):
        print(f"Error: {HEF_FILE} model not found. Please compile or download first.")
        sys.exit(1)

    camera = SmartSecurityCamera(HEF_FILE)
    camera.run()
