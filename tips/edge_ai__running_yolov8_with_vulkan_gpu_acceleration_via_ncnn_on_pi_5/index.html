    Edge AI: Running YOLOv8 with Vulkan GPU Acceleration via NCNN on Pi 5¶

    Implementing high-speed real-time computer vision usually requires dedicated neural processing units (NPU) like the Hailo-8L or Google Coral TPU. However, if you don't have this hardware, the Raspberry Pi 5 has a hidden weapon: its VideoCore VII GPU with native Vulkan API support.

    By leveraging ncnn (a high-performance neural network inference framework optimized for mobile and edge devices developed by Tencent), we can compile and run YOLOv8 directly on the Pi 5's GPU using Vulkan, achieving high frame rates without any external accelerator.

    This guide walks you through compiling the ncnn library with Vulkan support, converting YOLOv8 models, and running accelerated inference.

    Performance Comparison (CPU vs. Vulkan GPU)¶

    Model (YOLOv8 Nano) Hardware Backend Inference Latency Frame Rate (FPS)
    PyTorch / ONNX 4x Cortex-A76 CPU 120ms - 150ms ~7 FPS
    ncnn (Vulkan) VideoCore VII GPU 25ms - 35ms ~30 FPS (Real-Time)

    Step 1: Install GPU Drivers and Build Dependencies¶

    To use Vulkan, we need the latest Mesa drivers and build tools to compile ncnn.

    1
2

sudo apt install build-essential cmake git libopencv-dev vulkan-tools libvulkan-dev -y

    Verify that the VideoCore VII Vulkan driver is active on your system: 

    1

# Or inspect via command-line:
vulkaninfo | grep deviceName
    (You should see deviceName: Broadcom V3D 7.1.x or similar Broadcom GPU identification).

    Step 2: Compile ncnn with Vulkan Support¶

    Clone the ncnn repository and compile it from source. We must explicitly enable the -DNCNN_VULKAN=ON compiler flag.

mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release -DNCNN_VULKAN=ON -DNCNN_SYSTEM_GLSLANG=OFF -DNCNN_BUILD_EXAMPLES=ON ..
make -j$(nproc)
sudo make install

    Step 3: Convert YOLOv8 Model to ncnn Format¶

    To run a model in ncnn, we must export it from PyTorch into ncnn's optimized format, which splits the model into a .param (topology graph) and a .bin (weights) file.

    1. Export model to ONNX using Ultralytics¶

    In a Python virtual environment with ultralytics installed: 

    1
2
    pip install ultralytics
python3 -c "from ultralytics import YOLO; YOLO('yolov8n.pt').export(format='onnx')"

    2. Convert ONNX to ncnn using ncnn toolchain¶

    We will use the built-in compiler tool onnx2ncnn we compiled in Step 2: 

    1
    ~/ncnn/build/tools/onnx/onnx2ncnn yolov8n.onnx yolov8n.param yolov8n.bin

    #include "net.h"
#include <opencv2/core/core.hpp>
#include <opencv2/highgui/highgui.hpp>
#include <opencv2/imgproc/imgproc.hpp>
#include <iostream>
#include <vector>

struct Object {
    cv::Rect_<float> rect;
    int label;
    float prob;
};

class YOLOv8 {
public:
    ncnn::Net net;

    YOLOv8() {
        // 1. Enable Vulkan GPU Acceleration
        net.opt.use_vulkan_compute = true;
        net.opt.use_bf16_storage = true; // Use FP16 storage for 50% less RAM bandwidth
    }

    int load(const std::string& param_path, const std::string& bin_path) {
        if (net.load_param(param_path.c_str()) != 0) return -1;
        if (net.load_model(bin_path.c_str()) != 0) return -1;
        return 0;
    }

    int detect(const cv::Mat& bgr, std::vector<Object>& objects) {
        int width = bgr.cols;
        int height = bgr.rows;

        // Resize image to YOLO standard 640x640 input
        ncnn::Mat in = ncnn::Mat::from_pixels_resize(bgr.data, ncnn::Mat::PIXEL_BGR2RGB, width, height, 640, 640);

        // Normalize pixel values
        const float mean_vals[3] = {103.53f, 116.28f, 123.675f};
        const float norm_vals[3] = {1/255.f, 1/255.f, 1/255.f};
        in.substract_mean_normalize(mean_vals, norm_vals);

        ncnn::Extractor ex = net.create_extractor();
        ex.input("images", in);

        ncnn::Mat out;
        ex.extract("output0", out);

        // Process outputs (bounding boxes, class probabilities)
        // ... (standard post-processing loop)
        return 0;
    }
};

int main() {
    YOLOv8 detector;
    if (detector.load("yolov8n.param", "yolov8n.bin") != 0) {
        std::cerr << "Failed to load YOLOv8 model files." << std::endl;
        return -1;
    }

    cv::VideoCapture cap(0); // Open webcam or CSI camera
    if (!cap.isOpened()) {
        std::cerr << "Failed to open video source." << std::endl;
        return -1;
    }

    cv::Mat frame;
    while (cap.read(frame)) {
        std::vector<Object> objects;

        double start_time = ncnn::get_current_time();
        detector.detect(frame, objects);
        double end_time = ncnn::get_current_time();

        std::cout << "Inference Latency: " << (end_time - start_time) << " ms" << std::endl;

        // Draw bounding boxes on screen
        // cv::imshow("Vulkan YOLOv8", frame);
        if (cv::waitKey(1) == 27) break; // Exit on ESC
    }
    return 0;
}

    Step 5: Optimization for Maximum GPU Throughput¶

    To get the absolute best performance on Raspberry Pi 5:

    1. Enable FP16 (Half-Precision): By setting net.opt.use_bf16_storage = true and net.opt.use_fp16_arithmetic = true, you reduce the memory bandwidth requirements of the model by 50%, which is critical since the Pi 5's RAM bandwidth is shared between CPU and GPU.
    2. Increase GPU Memory Share: Ensure your Raspberry Pi allocates enough dynamic address space to Vulkan by adjusting memory allocation parameters if you run large models.
    3. Model Quantization: Using ncnn2table and ncnn2int8, you can perform INT8 post-training quantization, compressing your model weights and accelerating calculations by an additional 30%.

    By utilizing the Tencent ncnn library and Vulkan drivers, you can implement real-time 30FPS computer vision systems entirely local and free of external hardware costs on Raspberry Pi 5.
