    Edge AI: Building a Private Local AI Email Assistant on Raspberry Pi 5 with Ollama¶

    Reading and categorizing emails takes a significant amount of daily administrative time. Standard cloud-based AI email assistants require sending your private email messages to third-party APIs. For privacy-conscious developers and professionals, this is a major privacy concern.

    The Raspberry Pi 5 has a powerful 64-bit quad-core ARM Cortex-A76 processor. Combined with Ollama (an open-source runner for Large Language Models), you can run small, highly optimized models locally on-device.

    This guide provides a comprehensive tutorial for installing Ollama on the Raspberry Pi 5, setting up a Python agent that fetches emails securely over IMAP, using a local LLM to summarize and categorize them, and sending high-priority alerts with auto-drafted responses to a Discord channel.

    1. System Architecture¶

    The local AI assistant runs persistently as a system background service.

    graph TD A[Email Server: Gmail/Outlook] -->|IMAP over SSL| B[Python Agent on Pi 5] B -->|Check for Unread| B B -->|Send Content| C[Local Ollama: Llama 3] C -->|Return Category, Summary, Draft| B B -->|High Priority?| D{Decision} D -->|Yes| E[Send Webhook payload to Discord] D -->|No| F[Log Locally]

    To run models efficiently on the Pi 5's RAM limits, we will use a 3-billion-parameter model (Llama-3-8B quantized to 4-bit, or Llama-3.2-3B). These quantized models run comfortably within the memory bandwidth of the Raspberry Pi 5.

    2. Installing Ollama on Raspberry Pi 5¶

    Ollama provides official ARM64 Linux support, which runs natively on Raspberry Pi OS.

    Step 1: Run the Official Installer¶

    Log in to your Raspberry Pi 5 and download the installation script: 

    1
    curl -fsSL https://ollama.com/install.sh | sh
    This script detects the ARM64 architecture, installs the Ollama binary to /usr/local/bin, and registers a systemd system service named ollama.service.

    Step 2: Download a Quantized Model¶

    For CPU-based inference on the Pi 5, the Llama 3.2 (3B) or Phi-3 (3.8B) models are highly recommended. Download Llama 3.2: 

    1
    ollama run llama3.2:3b
    This fetches the model weights (approx. 2.0 GB). Once the download finishes, you can type prompts into the interactive terminal. Type /exit to close the interactive session.

import imaplib
import email
from email.header import decode_header
import os
import sys
import json
import time
import requests
from bs4 import BeautifulSoup

# Configuration
IMAP_SERVER = os.environ.get("IMAP_SERVER", "imap.gmail.com")
EMAIL_USER = os.environ.get("EMAIL_USER")
EMAIL_PASS = os.environ.get("EMAIL_PASS") # App Password
OLLAMA_API_URL = "http://localhost:11434/api/generate"
DISCORD_WEBHOOK_URL = os.environ.get("DISCORD_WEBHOOK_URL")

POLL_INTERVAL_SECONDS = 60

# Prompt template instructing the model to return structured JSON
SYSTEM_PROMPT = """
You are a professional email assistant. Analyze the incoming email and return a JSON object with the following fields:
1. "category": Choose exactly one from ["High-Priority", "Normal-Priority", "Newsletter", "Spam"].
2. "summary": A brief 1-sentence summary of the email content.
3. "auto_reply": A professional draft response if action is required, otherwise null.

Respond ONLY with valid JSON. Do not include markdown formatting, backticks, or any leading/trailing explanations.
"""

def clean_html(html_content):
    soup = BeautifulSoup(html_content, "html.parser")
    return soup.get_text(separator=' ', strip=True)

def fetch_unread_emails():
    # Connect to IMAP
    try:
        mail = imaplib.IMAP4_SSL(IMAP_SERVER)
        mail.login(EMAIL_USER, EMAIL_PASS)
        mail.select("inbox")
    except Exception as e:
        print(f"[-] Connection failed to {IMAP_SERVER}: {e}")
        return []

    # Search for unread messages
    status, messages = mail.search(None, 'UNSEEN')
    if status != 'OK' or not messages[0]:
        mail.close()
        mail.logout()
        return []

    email_list = []
    # Fetch list of IDs
    for num in messages[0].split():
        status, data = mail.fetch(num, '(RFC822)')
        if status != 'OK':
            continue

        raw_email = data[0][1]
        msg = email.message_from_bytes(raw_email)

        # Decode Subject
        subject, encoding = decode_header(msg["Subject"])[0]
        if isinstance(subject, bytes):
            subject = subject.decode(encoding or "utf-8", errors="ignore")

        # Decode From
        from_sender = msg.get("From")

        # Extract Body
        body = ""
        if msg.is_multipart():
            for part in msg.walk():
                content_type = part.get_content_type()
                content_disp = str(part.get("Content-Disposition"))
                if content_type == "text/plain" and "attachment" not in content_disp:
                    body = part.get_payload(decode=True).decode(errors="ignore")
                    break
                elif content_type == "text/html" and "attachment" not in content_disp:
                    body = clean_html(part.get_payload(decode=True).decode(errors="ignore"))
        else:
            body = msg.get_payload(decode=True).decode(errors="ignore")
            if msg.get_content_type() == "text/html":
                body = clean_html(body)

        email_list.append({
            "id": num,
            "sender": from_sender,
            "subject": subject,
            "body": body[:1500] # Limit size to fit LLM window comfortably
        })

    # Close connections
    mail.close()
    mail.logout()
    return email_list

def analyze_with_ollama(email_info):
    prompt = f"From: {email_info['sender']}\nSubject: {email_info['subject']}\nContent: {email_info['body']}"

    payload = {
        "model": "llama3.2:3b",
        "system": SYSTEM_PROMPT,
        "prompt": prompt,
        "stream": False,
        "format": "json"
    }

    try:
        response = requests.post(OLLAMA_API_URL, json=payload, timeout=90)
        if response.status_code == 200:
            result = response.json()
            return json.loads(result.get("response", "{}"))
        else:
            print(f"[-] Ollama API error: {response.status_code}")
    except Exception as e:
        print(f"[-] Failed to query Ollama: {e}")
    return None

def send_discord_alert(email_info, analysis):
    if not DISCORD_WEBHOOK_URL:
        return

    category = analysis.get("category", "Normal-Priority")
    summary = analysis.get("summary", "No summary provided.")
    reply_draft = analysis.get("auto_reply")

    # Set color based on priority
    color = 3447003 # Blue
    if category == "High-Priority":
        color = 15158332 # Red
    elif category == "Spam":
        return # Do not notify spam

    fields = [
        {"name": "From", "value": f"`{email_info['sender']}`", "inline": False},
        {"name": "Summary", "value": summary, "inline": False}
    ]

    if reply_draft:
        fields.append({"name": "Suggested Draft Reply", "value": f"```\n{reply_draft}\n```", "inline": False})

    payload = {
        "embeds": [{
            "title": f"📧 New Email: {email_info['subject']}",
            "description": f"Priority Category: **{category}**",
            "color": color,
            "fields": fields,
            "footer": {"text": "Pi 5 AI Email Assistant"}
        }]
    }

    try:
        requests.post(DISCORD_WEBHOOK_URL, json=payload)
    except Exception as e:
        print(f"[-] Failed to dispatch Discord webhook: {e}")

def main():
    if not EMAIL_USER or not EMAIL_PASS:
        print("Error: EMAIL_USER and EMAIL_PASS must be configured as environment variables.")
        sys.exit(1)

    print("[*] Local AI Email Assistant started. Checking inbox...")
    while True:
        unread = fetch_unread_emails()
        if unread:
            print(f"[*] Found {len(unread)} unread emails.")
            for mail_item in unread:
                print(f"[*] Analyzing email from {mail_item['sender']}...")
                analysis = analyze_with_ollama(mail_item)
                if analysis:
                    print(f"[+] Category: {analysis.get('category')} | Summary: {analysis.get('summary')}")
                    # Notify only if Normal or High priority
                    if analysis.get("category") in ["High-Priority", "Normal-Priority"]:
                        send_discord_alert(mail_item, analysis)
        time.sleep(POLL_INTERVAL_SECONDS)

if __name__ == "__main__":
    main()

    4. Configuring Gmail App Passwords¶

    If you use Gmail, Google requires an App Password to authorize connections via raw IMAP.

    1. Go to your Google Account Settings.
    2. Select Security.
    3. Under "How you sign in to Google", enable 2-Step Verification (required to generate App Passwords).
    4. Go to the App Passwords page.
    5. Create a new App Password, naming it "Raspberry Pi Assistant".
    6. Copy the generated 16-character code (this code bypasses MFA prompts for the script).

    6. Performance Benchmarks¶

    Below is a benchmark showing the inference latency of local models on a Raspberry Pi 5 (8GB) running on all 4 CPU cores:

    Model Size RAM Used Time to First Token Generation Speed Total Latency (600 tokens)
    Llama-3.2-3B (Q4_K_M) 2.0 GB ~2.5 GB ~0.4s 7.8 tokens/sec ~76.9 seconds
    Phi-3-3.8B (Q4_K_M) 2.2 GB ~2.7 GB ~0.5s 6.5 tokens/sec ~92.3 seconds

    Note: While 76 seconds of latency is slow compared to datacenter GPUs, it is perfectly acceptable for background email monitoring services.

    7. Conclusion¶

    By deploying Ollama locally on a Raspberry Pi 5, you have constructed a secure, offline, self-hosted AI agent that monitors your email inbox and alerts you of important items without sharing private correspondence with third-party servers.
